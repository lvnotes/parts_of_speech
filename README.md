# Детективи частин мови

Інтерактивна гра для закріплення теми «Частини мови» (Мовно-літературна освітня галузь, Нова українська школа). Учень стає мовним детективом і проходить три рівні, по 5 завдань на кожному.

## Посилання

https://lvnotes.github.io/parts_of_speech/

## Рівні

1. Хто є хто? Потрібно визначити, до якої частини мови належить слово: іменник, прикметник, числівник, займенник, дієслово чи прислівник.
2. Знайди підозрюваних. У реченні треба знайти всі слова потрібної частини мови. Можна вибрати кілька слів, а потім натиснути «Перевірити».
3. Службові слова. Виділене слово треба віднести до прийменників, сполучників, часток або самостійних частин мови. Тут трапляються слова-пастки, наприклад «що» як сполучник і «ти» як займенник.

## Як працює перевірка

- Правильні відповіді підсвічуються зеленим, неправильні — червоним.
- У завданнях на пошук слів пропущені слова позначаються зеленим пунктиром.
- Після кожної відповіді з'являється коротка підказка з питаннями до частини мови та прикладами.
- Наприкінці гра показує загальний результат із 15, бали за кожен рівень, звання (Стажер, Детектив, Головний детектив) і пораду, який рівень варто повторити.

## Особливості

- Слова та речення добираються випадково, тому кожна нова гра відрізняється від попередньої.
- Кнопка «Нова справа» запускає гру з іншим набором завдань.
